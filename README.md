# Toko Besi UD Sepakat Karawang — Website Resmi

Landing page performa tinggi (*high-conversion*) untuk **Toko Besi Cakar Ayam & Begel Karawang UD. Sepakat**.

Website ini dirancang dengan standar desain modern industrial tanpa efek *slop*, mengedepankan harga tangan pertama langsung dari pengrajin, jaminan 100% Besi Baru Full SNI, kalkulator kebutuhan tulangan interaktif dengan visualisasi blueprint CAD SVG, galeri dokumentasi foto fisik asli, katalog produk presisi, dan integrasi pemesanan langsung via WhatsApp.

---

## 🏗️ Fitur Unggulan

1. **Katalog Produk Rakitan 1:1 Presisi**:
   - Pondasi Cakar Ayam (Footplate)
   - Balok Sloof Jadi (3m & 4m)
   - Tiang Kolom Jadi (3m & 4m)
   - Cincin Begel (Lepasan Berbagai Ukuran)
   - Pondasi Sudut Batas Tanah (Cakar Gantung)
   - Pesanan Kustom Sesuai Gambar Kerja / Sketsa Tukang
2. **Kalkulator Kebutuhan Struktur Interaktif**:
   - Perhitungan jumlah cincin begel dan kebutuhan batang besi 12m secara instan.
   - Perhitungan titik pondasi cakar ayam tapak.
   - Dynamic CAD SVG Blueprint yang meregang proporsional secara *real-time*.
   - Banner estimasi langsung di layar *mobile* tanpa perlu *scroll*.
   - Tombol *stepper* `[-]` dan `[+]` ramah jempol untuk penyesuaian bentangan.
3. **Edukasi Kualitas Material (Besi Full SNI vs Banci)**:
   - Perbandingan diameter terukur jangka sorong (Besi 6mm, 8mm, 10mm, 12mm).
   - Format tabel teknis komprehensif pada desktop & kartu komparasi modular pada perangkat *mobile*.
4. **Hero Slideshow & Dokumentasi Marquee**:
   - Slideshow crossfade 10 detik dengan 5 foto otentik Google Maps & Street View UD Sepakat.
   - *Cosine alpha-feathering* selebar 420px yang meleburkan foto ke latar gelap secara mulus.
   - Ticker dokumentasi bergerak kontinu ke kanan tanpa jeda.
5. **Optimasi SEO Lokal & Data Terstruktur (Schema.org)**:
   - JSON-LD `@graph` (`LocalBusiness`, `HardwareStore`, `OfferCatalog`, `BreadcrumbList`, `FAQPage`).
   - Geo-targeting Karawang, Telukjambe Timur, Jawa Barat.
   - Meta Open Graph dan Twitter Card lengkap.
   - Seksi Tanya Jawab (FAQ) interaktif dengan akordeon mandiri.
6. **Responsivitas Multi-Device**:
   - Teruji dan proporsional di seluruh resolusi: Desktop (1440px), Laptop (1280px), iPad Pro (1024px), iPad Portrait (768px), dan Mobile (360px & 390px).

## 🚀 Menjalankan Secara Lokal

Cukup buka berkas `index.html` langsung di peramban web atau jalankan server statis lokal:

```bash
# Menggunakan Python 3
python -m http.server 3000

# Atau menggunakan Node.js npx serve
npx serve .
```

Buka `http://localhost:3000` di peramban Anda.
